# 개인 비서 MVP

까먹기 쉬운 일정과 할 일을 빠르게 등록하고, 오늘 할 일과 놓친 일을 한 화면에서 확인하는 React MVP입니다.

## 포함된 기능

- 오늘 할 일, 놓친 일, 예정, 완료 필터
- 할 일 제목, 메모, 날짜/시간, 미리 알림, 반복, 중요도 입력
- `내일 오후 3시에 병원 예약 30분 전` 같은 자연어 입력 해석
- 브라우저 localStorage 저장
- 브라우저 알림 권한 요청
- PWA 설치용 매니페스트와 서비스 워커
- 알림 시점이 지난 미완료 항목 자동 표시
- 10분 미루기, 완료, 반복 항목 다음 일정 갱신, 삭제

## 실행

```bash
npm install
npm run dev
```

기본 주소는 Vite가 표시하는 로컬 주소입니다. 현재 세션에서는 `http://127.0.0.1:5181/`로 실행되었습니다.

## 설치

브라우저 주소창의 설치 아이콘을 누르거나, 앱 안의 `앱 설치` 버튼이 보일 때 눌러 설치할 수 있습니다. 설치 버튼은 브라우저가 설치 조건을 만족했다고 판단할 때 표시됩니다.
